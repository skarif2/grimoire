$ARGUMENTS

Load and follow the `improve-architecture` skill to run an architectural review.

The skill will:
1. Detect the project and load domain context and ADRs
2. Explore the codebase for shallow modules and architectural friction
3. Produce a visual HTML report (opened in the browser) with before/after diagrams
4. Drop into a grilling conversation on the candidate you choose
5. Update context files and create ADRs as decisions crystallise
